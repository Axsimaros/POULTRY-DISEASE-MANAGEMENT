# POULTRY-DISEASE-MANAGEMENT
Robot Locomotion & PID ControlTo ensure the poultry disease identifying system navigates coops safely and efficiently, I optimized the robot's movement using a PID (Proportional-Integral-Derivative) algorithm.What this means:Smoother Navigation: The PID controller continuously calculates an error value and applies real-time corrections to the motors. This eliminates jerky, erratic movements that could distress the poultry.Precision Tracking: It allows the robot to follow paths or waypoints accurately, ensuring consistent camera angles for highly reliable disease detection.Stable Hardware: By tuning the Proportional (\(K_{p}\)), Integral (\(K_{i}\)), and Derivative (\(K_{d}\)) gains, the robot can dynamically adjust to uneven terrain or sudden shifts in weight without tipping or drifting.
